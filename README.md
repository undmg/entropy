# ORACLE.EXE

The Oracle of Delphi lives inside a haunted old computer.
Type a question and she answers with a cryptic prophecy.

Live: https://undmg.github.io/entropy/ (add `#desktop` to skip the boot screen)

- Same question on the same day gets the same answer.
- Desktop extras: `do_not_open.txt`, offerings for Apollo, a full recycle bin, a start menu you can't really shut down.
- Optional temple hum, generated live with the Web Audio API (no audio files).

Plain HTML, CSS and JavaScript. No build step.
